The Corridor

A hand-drawn infinite corridor with doors leading to four immersive 3D rooms. Built with custom WebGL shaders, procedural geometry, and GSAP-powered animations for seamless transitions.

Technology

Powered by React 19, React Three Fiber (R3F), Three.js, and GSAP. Features custom GLSL shader materials, device-aware performance tiering, and real-time 3D rendering at 60fps.
